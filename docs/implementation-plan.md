# Historical implementation plan

This file records the original v0 product scope. It is not current setup or
operational guidance. The current architecture is PostgreSQL-only; use
[ARCHITECTURE.md](../ARCHITECTURE.md), [CONTEXT.md](../CONTEXT.md), and the
[PostgreSQL ledger](postgresql-migration.md) for owners and verification.

The original plan covered a local FastAPI/React investment panel, Arco/Birdclaw
evidence, deterministic market jobs, transparent scoring, research packets,
portfolio context, thesis tracking, and no automatic trading. Those product
boundaries remain useful historical context. Its storage and job instructions
are retired.
